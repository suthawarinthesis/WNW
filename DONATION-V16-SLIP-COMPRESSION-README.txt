Donation V16 — Automatic Slip Image Compression

- รูปสลิป JPG / PNG / WebP จะถูกบีบอัดบน Browser ก่อนอัปโหลดเข้า Supabase Storage
- ด้านยาวสูงสุดประมาณ 1600 px และปรับคุณภาพแบบหลายรอบเพื่อพยายามให้ไฟล์อยู่ราว 1.2 MB หรือต่ำกว่า
- ระบบจะแสดงขนาดก่อนและหลังบีบอัด
- ไฟล์เล็กกว่า ~550 KB จะไม่บีบซ้ำเพื่อรักษาคุณภาพ
- PDF ไม่ถูกบีบอัด และจำกัด 10 MB
- รูปต้นฉบับรับได้สูงสุด 20 MB ก่อนบีบอัด
- ไม่ต้องรัน SQL เพิ่ม
