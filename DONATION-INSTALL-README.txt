WNW Donation System V7 - Clean Install

1) Supabase > SQL Editor > New query
2) Paste the ENTIRE contents of DONATION-CLEAN-INSTALL.sql
3) Do not highlight only part of the SQL
4) Press Run once
5) Success / No rows returned = installation completed

This SQL is based on the current full database schema provided on 2026-10-04.
It creates only Donation objects and does not modify Alumni, Personnel,
Student Portal, Admission, News, Achievements, University Admission, or site_settings.
