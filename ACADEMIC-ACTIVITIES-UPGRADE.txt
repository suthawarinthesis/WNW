ACADEMIC + STUDENT ACTIVITIES + PERSONNEL DHARMA LEVELS
======================================================

เพิ่มในเวอร์ชันนี้
1) หน้าเว็บหลัก: วิดีโอแนะนำโรงเรียนแยกเป็นกล่องเฉพาะ
2) /academic/ ฝ่ายวิชาการ
   - ประกาศฝ่ายวิชาการ
   - เอกสารวิชาการ
   - เอกสารการเงิน
   - เอกสารประกัน/ประเมินคุณภาพ
   - /academic/manager/ สำหรับผู้ดูแล
3) /activities/ ฝ่ายกิจกรรมนักเรียน
   - โพสต์ข้อความ + หลายภาพ
   - เรียงลำดับภาพได้
   - เลือกชุดภาพอยู่บน/ล่างข้อความ
   - /activities/manager/ สำหรับผู้ดูแล
   - รายการล่าสุดแสดงหน้าเว็บหลัก
4) บุคลากร
   - วุฒินักธรรมสูงสุด: ตรี / โท / เอก
   - วุฒิบาลีสูงสุด: ประโยค 1-2 / ป.ธ.3-9
   - แสดงใน Modal รายละเอียดบุคลากร

ติดตั้ง
------
1. อัปโหลดไฟล์ทั้งหมดทับเว็บไซต์เดิมบน GitHub Pages
2. Supabase > SQL Editor
3. รันไฟล์: supabase/academic-activities-personnel-upgrade.sql เพียงครั้งเดียว
4. Hard Refresh: Ctrl + F5

การอัปโหลดไฟล์/ภาพ
-------------------
Academic Manager และ Student Activities Manager ใช้ bucket เดิมชื่อ site-media
จึงไม่ต้องสร้าง Storage bucket ใหม่ หากติดตั้งระบบเว็บไซต์เดิมครบแล้ว

วิดีโอแนะนำโรงเรียน
-------------------
ใช้ค่า Website Manager > บริการ/ลิงก์ > วิดีโอแนะนำโรงเรียน
แนะนำใช้ลิงก์ YouTube เช่น https://www.youtube.com/watch?v=VIDEO_ID
